# Chromodor

A Chrome dinosaur-style endless runner where you play as a **matador** dodging charging bulls.

## Play
Open the live site (after Vercel deploy) or open `index.html` locally in any modern browser.

**Controls:** Space / ↑ / Click / Tap to jump.

## Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and import this repository.
2. Deploy — no build settings needed (static HTML).
3. The game will be live at your Vercel URL.

## Features
- Classic side-scrolling endless runner
- Matador with red cape, montera hat, and running animation
- Charging bulls with horns, galloping legs, and angry eyes
- Increasing difficulty
- Local high score
- Touch + keyboard + mouse support
- Pure vanilla HTML5 Canvas (no dependencies)
